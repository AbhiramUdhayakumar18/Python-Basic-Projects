# 🐍 Python Beginner Projects

A collection of beginner-friendly Python projects built while learning Python programming. This repository contains small interactive programs that practice fundamental concepts such as loops, conditionals, functions, user input, randomization, and working with external libraries.

## 📂 Projects

### 1. 🎲 Dice Roll
A simple dice-rolling program that uses Python's `random` module to generate random dice values.

### 2. 🔢 Guess the Number
A number-guessing game where the player tries to guess a randomly generated number.

### 3. 🔳 QR Code Generator
A Python program that generates a QR code from user-provided text or a URL and saves it as an image.

**Dependency:** Pillow and the QR code library, if used by the implementation.

### 4. ✊ Rock Paper Scissors
A classic Rock Paper Scissors game where the player competes against the computer.

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your system
- Git installed on your system

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-projects
   ```

3. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Activate the virtual environment on Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

### Install Dependencies

For the QR code generator, install the required libraries if your script uses them:

```bash
python -m pip install qrcode[pil] Pillow
```

## ▶️ Running the Projects

Run any project from the terminal. For example:

```bash
python Dice_roll.py
```

Other available scripts:

```bash
python guess_number.py
python QR_code_generator.py
python Rock_paper_scissors.py
```
